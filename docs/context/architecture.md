# Architecture

> Derived from `documentation/30-architecture/` and ADR-0003..0005 (`documentation/60-decisions/`) — those files are authoritative. Update both together.

## Stack

- **Runtime/hosting:** Cloudflare Workers, free plan — one Worker serves everything: static assets (SPA), `/api/*`, and the `scheduled()` cron handler (ADR-0003).
- **Database:** Cloudflare D1 (SQLite-class, managed) — the single canonical copy of all data. Access via Drizzle ORM (`drizzle-orm/d1`).
- **Frontend:** React 19 single-page application, TypeScript strict, bundled by Vite with `@cloudflare/vite-plugin`; PWA via `vite-plugin-pwa` in `injectManifest` mode with a hand-owned `src/sw.ts` (ADR-0004/0005).
- **API:** Hono 4 in the Worker — bearer-token middleware on every route (single user, no accounts).
- **Notifications:** Web Push (`web-push` library under `nodejs_compat`), fired by the Workers cron trigger.

## Architectural pattern

Thin client over a canonical server store: the PWA holds no authoritative state and there is **deliberately no merge, sync, or offline-write logic anywhere** (ADR-0003). SPA without SSR/RSC is a recorded final position, not deferred debt (ADR-0005).

## Planned repository layout (ADR-0005; becomes real at scaffold)

| Path | Contents |
|---|---|
| `src/app/` | React SPA + typed api-client |
| `src/sw.ts` | Service worker: push, notificationclick, app-shell cache |
| `src/shared/` | Pure domain logic (recurrence, dates) + shared types |
| `src/worker/` | Hono API: fetch + scheduled entry → `routes/`, `push/`, `db/` |
| `migrations/` | Numbered SQL generated by drizzle-kit |
| `public/` | PWA manifest, icons |
| `documentation/` | Authoritative project docs (vision, requirements, ADRs) |
| `docs/` | This relay context system (derived) |

Per-target tsconfigs with project references make an app/worker boundary violation a compile error.

## Data safeguards (binding, ADR-0003)

- Day-1 export of 100% of the data as JSON + iCalendar (FR-042).
- Automated export snapshots shipped to the owner's PC — Cloudflare never holds the only copy (FR-043).
- No offline write queue without a superseding ADR.
- Every API route requires the auth token; only the PWA shell is unauthenticated.

## External services

- **Cloudflare** (Workers, D1, cron) — platform; can technically read D1 (consent recorded in ADR-0003).
- **Web Push service endpoints** (browser vendors) — deliver notifications.
- **Google Calendar** — NOT integrated; pending decision 4 in `documentation/60-decisions/index.md`.
