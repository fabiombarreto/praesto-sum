### Update toast on a second build (step 11)

A `praesto-preview` configuration (`npx vite preview --port 4173 --strictPort`)
was added to `.claude/launch.json`. First load of the built app on
`http://localhost:4173/`: `sw.js` registered, `active` and controlling. A
byte change appended to `dist/client/sw.js` was served by the same process as
**304 Not Modified** (the preview's asset ETags are computed at start-up), so
the worker saw no update; after restarting the preview process the reload
fetched `/sw.js` **200**, installed the new worker and
`registration.waiting === true` — the exact state in which
`registerSW`'s `onNeedRefresh` fires and `main.tsx` shows the `sw-update`
toast. **The toast itself was not visible** because the toast host is a row of
the *Hoje* shell (`TodayScreen`) and the tab showed the transitional token
gate; the store keeps `current`, so the toast surfaces once *Hoje* mounts. The
on-screen *Atualizar* (reload on `controlling`) and *Depois* (suppressed for
the session — `test/toast.test.ts` "Depois" sequence) checks are owed to the
owner (pane with a token, or the phone after the next deploy, where the real
old→new worker hand-over happens).

### Defect found and fixed — focus not visible on the two text inputs

Before the fix, the sweep showed `outline-style: none` on `#capture-title`
and on the inline-title input while both matched `:focus-visible`: the plan's
class strings (lines 605 and 681) carried Tailwind's `outline-none`, and the
utilities layer wins over the project's base `:focus-visible` rule
(`styles.css` 63–67), leaving only the dark 4 px halo — invisible on the dark
surfaces. Guidelines line 54: "never `outline: none` without a replacement."
The implementer was re-dispatched with that finding as `prior_feedback`
(attempt 2, `attempts/2/`): `InlineTitle.tsx` dropped `outline-none` (the
base ring applies), `CaptureDeck.tsx` kept the bare field and gave the bordered
`<form>` box the replacement ring through
`has-[input:focus-visible]:outline-2 … outline-accent … outline-offset-2 …
[box-shadow:0_0_0_4px_var(--color-bg)]`. Re-measured after HMR: inline input
`solid 2px rgb(245,165,36)` + halo ✔; deck box `solid 2px rgb(245,165,36)` +
halo while the field has focus ✔, `none` while *Adicionar* has focus ✔.
Levels 1–3 re-run green; sizes moved by +54 B JS / +88 B CSS gzip. The plan's
two literal class strings are therefore superseded — recorded for A6's
divergence list.
